# Tennis Duel

A real-time two-player browser tennis game built with Node.js, Express and Socket.IO.

## Run locally
1. Install Node.js 20+.
2. Run `npm install`.
3. Run `npm start`.
4. Open http://localhost:3000 in two browser windows.

## Deploy
Deploy this folder to a Node-compatible host such as Render, Railway, or another Web Service host. The start command is `npm start`.
